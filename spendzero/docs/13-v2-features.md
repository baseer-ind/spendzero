# V2 Features

- Remaining high-traffic categories: Grocery, Travel, Movies, Hotels.
- Discover hub: AI search + voice search.
- Achievements + streak mechanics (opt-in, non-nagging reminders only).
- Push notifications (Firebase) — strictly value-framed ("Your Goa Trip
  goal is 60% there"), never guilt-framed.
- Account sync/merge polish: multi-device, restore-from-backup flow.
- Full admin analytics dashboard (funnels, cohorts, goal-completion
  rates).
- Hindi localization completed across all live categories.
- Goal sharing (optional, opt-in): share a goal's progress card with
  friends/family, no social graph required.

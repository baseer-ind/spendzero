# V3 Features

- Remaining categories: Beauty, Electronics, Vehicles, Real Estate,
  Services, Books, Gaming, Gifts, Pets, Jewellery, Healthcare, Music.
- Configurators: vehicle builder, electronics dream-setup builder,
  real-estate interior package builder (all simulation-only, EMI
  calculator clearly labeled illustrative/non-binding).
- Cross-category AI planner ("plan my Europe trip under ₹2L" spanning
  flights/hotels/activities into one craving-session bundle).
- Additional regional languages (Tamil, Telugu, Bengali, Marathi),
  prioritized by signup geography.
- Optional social layer (kept minimal and opt-in, given the product's
  core promise is personal, non-comparative savings — any leaderboard/
  comparison feature must be reviewed against the no-guilt principle
  before building).
- "Year in review" style shareable savings recap.
- Web companion (read-only goal-progress viewer for sharing outside the
  app).

# Roadmap

| Phase | Timeframe | Theme | Key deliverables |
|---|---|---|---|
| Phase 0 | Weeks 1–2 | Foundations | Repo scaffolds, design tokens, guest-session model, DB schema/migrations, CI skeleton |
| Phase 1 — MVP | Weeks 3–10 | Core loop, guest-first | Food + Shopping categories full loop, Craving Completed screen, Goals (presets + custom), guest mode end-to-end, no signup wall |
| Phase 2 | Weeks 11–16 | Breadth + soft conversion | Grocery, Travel, Movies; Discover (text+AI search); contextual sign-in prompt; account sync/merge |
| Phase 3 | Weeks 17–22 | Retention mechanics | Streaks, achievements, History tab polish, push notifications (non-nagging, opt-in) |
| Phase 4 | Weeks 23–28 | Remaining categories | Hotels, Beauty, Electronics, Vehicles, Real Estate, Services, Books, Gaming, Gifts, Pets, Jewellery, Healthcare, Music |
| Phase 5 | Weeks 29–32 | Hardening & launch prep | Admin dashboard, analytics dashboards, financial-claims copy review pass, security review, store submission |
| Launch | Week 33+ | GA | Phased rollout, see `15-launch-strategy.md` |
| Post-launch | — | See `13-v2-features.md` / `14-v3-features.md` | |

See `12-mvp-scope.md` for the exact MVP cut line and `18-development-plan.md`
for milestone-level detail with exit criteria.

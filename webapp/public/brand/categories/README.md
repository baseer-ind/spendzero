# SELFly category hero images

The Today screen tiles load a 4:5 hero photo per category from this folder. If a
file is missing, the tile falls back to an on-brand generated backdrop — never a
broken image. Drop in real photos to make Today feel like a real marketplace.

| File               | Category      |
|--------------------|---------------|
| `food.webp`        | Food          |
| `electronics.webp` | Electronics   |
| `grocery.webp`     | Grocery       |
| `shopping.webp`    | Shopping      |
| `travel.webp`      | Travel        |
| `entertainment.webp` | Entertainment |
| `beauty.webp`      | Beauty        |
| `home.webp`        | Home          |

Specs and art direction: see `docs/SELFLY_LAUNCH_IMAGE_BRIEF.md` (section B).
`.webp`, 1200×1500, < 180 KB, warm neutral, calm, no brand logos / watermarks.
